# Festival furniture functions

The original model identities and native 128×128 textures are preserved. These exact models now perform the named game actions below. The separate festival-cart companion covers the nine original procession/gift carts; this document covers clocks, weather, paid counters and emitted light.

## Existing saved furniture

An old FUR1/FUR2 decoration record keeps its exact ID, owner and pose. The old decorative accent flag is cleared **in memory only** for the exact newly functional readouts, food counters and nine movable festival carts. Opening a snapshot does not itself write a migration. Other records and unsupported invalid settings are not silently rewritten.

The five former light ornaments can still load their old unbound placements. Those placements emit no light and clearly explain the missing connection. Remove the old placement, connect a real owned dry `LIGHT`, and place the same entitlement again. A new unbound light placement is refused. Binding ownership, backing material, full property, range, visibility and exclusive reservation checks continue to apply.

Structural geometry has a separate compatibility revision. An old structure is never silently enlarged across someone else's blocks or property; the structural runtime's deliberate placement/recommissioning rules apply independently of the food-counter role.
